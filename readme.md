# ChainNode

## Features

+ fetch information of node status. 
+ batch initialize online nodes. 
+ batch add online nodes in the future as you wish. 
+ batch manage nodes. [start, stop, restart] 
+ TLS option for establishing connection between master, node and client that uses API. 
+ firewall option,  allow all and allow only, for master's security. 
+ register streams for receiving live data, like app status changed, log, node status, storage status, transaction log. 
+ provides token verification between client and Cometbft ABCI app. 
+ provides GUI to edit configuration files of node and master. 
+ provides javascript API to interactive with master. 
+ provides a test web page to interactive with Cometbft ABCI app to read & write data. 
+ running node and master as a windows services.
